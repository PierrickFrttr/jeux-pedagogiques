Données personnelles

Les visiteurs n’ont pas besoin de compte. Le site ne contient aucun formulaire, ne dépose aucun cookie et ne mesure pas l’audience.

  • Progression dans les missions : certaines missions enregistrent vos réponses et votre avancement dans votre navigateur (stockage local), pour que vous puissiez reprendre plus tard. Ces informations restent sur votre appareil, elles ne nous sont pas envoyées. Vous pouvez les effacer depuis les réglages de votre navigateur.

  • Hébergement : comme tout hébergeur, GitHub peut enregistrer des données techniques de connexion (adresse IP, date, page consultée) pour la sécurité du service. Voir la déclaration de confidentialité de GitHub.
  • Espace formateur : réservé aux formateurs disposant d’un accès. Les comptes ne contiennent qu’un identifiant et des données chiffrées ; la connexion est conservée dans le navigateur du formateur.
